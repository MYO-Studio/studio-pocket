# Security policy

## Reporting a vulnerability

Please report security problems privately, through this repository's GitHub security advisory
form: open the **Security** tab and choose **Report a vulnerability**. Never report a vulnerability
in a public issue, pull request or discussion.

If the form is unavailable, email the maintainer directly at stuart@myostudio.co.uk, with
"Studio Pocket security" in the subject. Do not open an issue.

Say what you found, how to reproduce it, and which release or commit you tested. If the problem can
affect a player (for example, a way to get an APK the release key did not sign onto a Y2, or a write
to the wrong part of a player's storage), say so, because those come first.

## Disclosure

The disclosure window is **90 days from the report**. After that you may publish your findings,
whether or not a fix has been released. If a fix ships sooner, the release notes credit you unless
you ask them not to.

## Supported versions

Only the **latest release** is supported. Fixes go into a new release; older releases are not
patched.
