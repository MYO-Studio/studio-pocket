# Third-party components and licensing audit

This covers what this repository builds and ships. The status of each item is what could be confirmed from source or release metadata; "unconfirmed" means no licence text was found.

This repository's own code is licensed under GPL-3.0-only, or under a commercial licence from the copyright holder: see `LICENSE`, `COPYING.commercial` and the header at the top of each source file. mtkclient and e2fsprogs are run as separate programs; nothing below is linked into our code except where a row says so.
